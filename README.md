# Hot Or Cold Game

A C#-based console application where players must find a hidden point on a 15x15 coordinate grid. The game calculates the distance to the target and provides dynamic feedback based on the player's movement.

Key Features:

    Distance Logic: Uses Manhattan distance to provide "Warmer" or "Colder" hints.

    Attempt Tracking: Precisely counts valid moves to measure player performance.

    Input Validation: Handles user input safely to prevent crashes.
